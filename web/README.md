# CrossLearn AI web demo

Node.js 24+; no dependencies to install.

```powershell
npm.cmd run dev
```

Open http://127.0.0.1:5173/. Stop with Ctrl+C.

`npm.cmd test` runs seven automated checks. `npm.cmd run build` generates `dist`. `npm.cmd run preview` serves that build.

See `../README.md` for the walkthrough, verification limits and M2 plan. M1 uses only synthetic local data. Content is pending teacher validation. There are no AI calls or secrets. Browser speech requires a supported device voice. Mobile visual QA remains unverified because browser automation was unavailable.
